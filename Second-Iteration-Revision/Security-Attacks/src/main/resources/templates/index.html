⚠️ Security Attacks Demo

⚠️ WARNING

This application demonstrates common security vulnerabilities. NEVER use these patterns in production code!

1. CSRF (Cross-Site Request Forgery)

Demonstrates how an attacker can trick authenticated users into performing unwanted actions.

Go to Login (Step 1)

2. XSS (Cross-Site Scripting)

Demonstrates stored XSS where malicious scripts are saved in the database and executed when rendered.

Go to Comments Page

3. SQL Injection

Demonstrates how SQL queries can be manipulated through user input.

Test with: ?name=AA or ?name=' OR '1'='1

Normal Query SQL Injection

4. CORS (Cross-Origin Resource Sharing)

CORS is configured to allow cross-origin requests (check SecurityConfig.java)

This enables the CSRF attack demo from a different origin.
